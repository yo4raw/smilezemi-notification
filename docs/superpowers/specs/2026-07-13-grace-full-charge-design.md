# 全員のおたすけ満タンチャージ(v1.2移行) 設計書

作成日: 2026-07-13
ステータス: ユーザー承認済み

## 要件

現在の子供たち全員のおたすけポイントを3(上限)にする。

## 仕様判断

- **一度きりの満タンチャージ**であり、ルール変更ではない: 新規ユーザーの初期おたすけは1のまま、リセット後は0のまま、上限3・10日ごと+1も不変
- 本番データは actions/cache 内にあり直接編集できないため、実績のあるデータバージョン移行方式(読み込み時に一度だけ適用)を使う

## 設計 (`src/streak.js` のみ)

1. `saveStreakData` をバージョン `'1.2'` で保存に変更
2. `loadStreakData` は `'1.0'` / `'1.1'` / `'1.2'` を受理し、**1.2未満(1.0または1.1)を読み込んだとき全ユーザーの `grace = GRACE_MAX`(3)を設定**する。従来の1.0→1.1移行(最低1付与)はこの新移行に包含されるため統合する
3. 次回保存で1.2になるため再付与はない。以降消費した分は通常どおり減る

## テスト

- 1.0 / 1.1 データの読み込みで grace 0/1/2 がすべて3になること(streakは不変)
- 1.2 データの読み込みでは grace 0 でも変化しないこと
- 保存ファイルの version が 1.2 であること
- 未知バージョンはエラー(既存)

## 適用タイミング

リリース後の初回実行(夜20時または朝7時)で自動適用され、その回の通知から「🛟 おたすけ: 3/3」と表示される。
