# おたすけ満タン中の毎日ボーナスポイント設計

日付: 2026-07-13
ステータス: 承認済み

## 目的

ボーナスポイントの獲得を「10日ごとのマイルストーン到達時、おたすけ満タンの場合のみ+1」から「**おたすけ満タン中はストリーク条件を満たして学習した日ごとに毎日+1**」に変更する。おたすけを満タンに保ったまま学習を続けるインセンティブを強化する。

## 要件

- おたすけが満タン(3)の状態でストリーク条件(完了数しきい値)を満たして学習した日は、毎日ボーナス+1
- **満タン中はマイルストーン判定を行わない**。10日ごとの節目の日も他の日と同じ+1(重ね掛けなし)、🎉のお祝い文面も出さない
- おたすけ3未満のときの動作は従来どおり: 10日ごとのマイルストーン日におたすけ+1(`event: 'milestone'`)、節目以外は報酬なし
- 未学習日(おたすけ消費・リセット)、streak 0 時の中立処理、月次清算のロジックは無変更
- ボーナスは従来どおりリセットでも消えず、毎月1日の月次清算で0にリセットしてお小遣いとして支給する

## 設計

### src/streak.js — confirmDay

学習日(`studied === true`)の分岐を次の順に整理する:

1. `state.grace >= GRACE_MAX`(満タン)なら: `bonus + 1`、おたすけとストリークはそのまま加算(`streak + 1`)、`event: 'bonus'`。マイルストーン判定はしない
2. 満タンでなければ: 従来どおり `streak % MILESTONE_INTERVAL === 0` を判定し、節目なら `grace + 1` で `event: 'milestone'`、それ以外は `event: 'none'`

`isStudied` / `updateStreaks` / `settleBonuses` / データ入出力は無変更。

### src/streak.js — formatStreakInfo

- `event: 'bonus'` の表示を「💰 おたすけ満タンのためボーナス+1(合計XP)」に変更(🎉の連続達成文面は出さない)
- `event: 'milestone'` / `grace_used` / `reset` の表示は無変更
- 1行目の「💰 ボーナス: XP」表示(bonus > 0 のとき)は無変更

### 影響範囲

- `streak_data.json` の形式・バージョンは無変更(データ移行なし)
- 夜通知(`src/index.js`)・朝通知(`src/morning-index.js`)はどちらも `confirmDay` 経由のため自動反映。エントリポイントのコード変更なし
- 月次ボーナス清算(`src/monthly-bonus-index.js`)は無変更(ボーナスが貯まる速度が上がるだけ)

## テスト

`tests/streak.test.js` を更新・追加する:

- 満タン+学習日(節目以外)でボーナス+1、`event: 'bonus'`
- 満タン+学習日(節目=10の倍数)でもボーナス+1のみ(重ね掛けなし)、おたすけは満タンのまま
- おたすけ3未満のマイルストーン日は従来どおりおたすけ+1でボーナス不変(`event: 'milestone'`)
- おたすけ3未満の節目以外の学習日は報酬なし(`event: 'none'`)
- 未学習日はボーナス不変(おたすけ消費・リセットの既存テストで担保)
- `formatStreakInfo`: `event: 'bonus'` の文面が「💰 おたすけ満タンのためボーナス+1(合計XP)」であること

既存の「マイルストーン時のみボーナス」を前提としたテストは新仕様の期待値に書き直す。
